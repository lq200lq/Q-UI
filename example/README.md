# example

组件与设计系统的展示示例（不进入业务包逻辑）。

| 路径 | 说明 | 路由 |
|------|------|------|
| `layout/` | 应用布局壳（Sidebar + Topbar） | `/example/layout` |
| `components/` | Q 组件总览（预览 + 可折叠代码） | `/example/components` |
| `icons/` | QIcon 全量图标墙 | `/example/icons` |
| `_shared/ExampleBlock.vue` | 示例块：预览 / 查看代码 / 复制 | — |

本地：`npm run dev` 后打开对应路由。
